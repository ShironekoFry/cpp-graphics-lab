# 类型转换

## 类型转换会产生新值

类型转换不会修改提供数据的原始值或对象，而是使用原始数据生成一个转换后的新值。

例如，将一个值为 `5` 的 `int` 变量 `y` 转换为 `double` 时：

- `y` 的类型仍然是 `int`；
- `y` 的值仍然是 `5`；
- 转换操作会产生一个值为 `5.0` 的临时 `double` 对象。

这个临时对象随后可以作为实参传递给函数。

## 显式类型转换

`static_cast` 可以明确地把表达式转换成指定类型：

```cpp
static_cast<new_type>(expression)
```

例如，把 `char` 转换为 `int`，查看字符对应的整数编码：

```cpp
char ch{'a'};
std::cout << static_cast<int>(ch) << '\n';
```

`static_cast` 也可以用于数值类型之间的转换，例如将 `int` 转换为 `double`，或者在有符号整数和无符号整数之间转换。
